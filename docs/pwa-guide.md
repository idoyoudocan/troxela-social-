# Troxela PWA গাইড — troxela.store-কে অ্যাপের মতো বানানো

> এই গাইডে দেখানো হয়েছে troxela.store-এ Hisab-এর মতো **Pure PWA** (Progressive Web App) কীভাবে সেটাপ করা হয়েছে, এটা কীভাবে কাজ করে, আর ভবিষ্যতে আপনি নিজে কীভাবে আপডেট করবেন।

---

## ১. PWA কী?

PWA মানে ওয়েবসাইটটাই ফোনে **অ্যাপের মতো** চলে — আলাদা করে Play Store-এ অ্যাপ বানাতে হয় না।

PWA থাকলে যা যা হয়:

- ফোনের হোম স্ক্রিনে Troxela-র আইকন বসে, অ্যাপের মতো খোলে (ব্রাউজারের ঠিকানা বার থাকে না)।
- দ্বিতীয়বার থেকে পাতা **অনেক দ্রুত** খোলে — স্টাইল, ছবি ফোনেই ক্যাশ থাকে।
- ইন্টারনেট না থাকলেও আগের দেখা পাতা বা একটা সুন্দর "ইন্টারনেট নেই" পাতা দেখায়।
- ভিজিটরকে **"অ্যাপ ইনস্টল করুন"** ব্যানার দেখায়।

এর জন্য ৩টা জিনিস লাগে — **HTTPS** (troxela.store-এ আছেই), একটা **manifest** ফাইল, আর একটা **service worker** ফাইল।

## ২. কী কী ফাইল যোগ করা হয়েছে

| ফাইল | কাজ |
|---|---|
| `public/manifest.json` | অ্যাপের পরিচয়পত্র — নাম, রং, আইকন, কীভাবে খুলবে |
| `public/sw.js` | Service worker — ক্যাশের মালিক, অফলাইন ব্যবস্থা |
| `public/icons/icon-192.png` | ১৯২×১৯২ আইকন (অ্যান্ড্রয়েড) |
| `public/icons/icon-512.png` | ৫১২×৫১২ আইকন |
| `public/icons/icon-512-maskable.png` | ৫১২×৫১২ maskable আইকন (অ্যান্ড্রয়েড আইকনের আকৃতি যেমনই হোক, মাঝের অংশ কাটে না) |
| `public/icons/apple-touch-icon.png` | ১৮০×১৮০ আইকন (আইফোনের হোম স্ক্রিন) |
| `resources/views/partials/pwa-head.blade.php` | `<head>`-এর PWA ট্যাগগুলো (manifest লিংক, theme-color, Apple ট্যাগ) |
| `resources/views/partials/pwa-banner.blade.php` | "অ্যাপ ইনস্টল করুন" ব্যানার + service worker রেজিস্টার করার কোড |
| `resources/views/layouts/app.blade.php` | উপরের দুটো partial এখানে যুক্ত হয়েছে — তাই সাইটের **সব পাতায়** PWA কাজ করে |
| `public/css/app.css` | ব্যানারের স্টাইল (শেষে যোগ করা) |
| `tests/Feature/PwaTest.php` | ৪টা টেস্ট — manifest, service worker, আইকন, হেড ট্যাগ যাচাই করে |

সব আইকন সাইটের আসল লোগো (`images/logo-mark.png`, সবুজ "T") থেকে বানানো — নতুন করে ডিজাইন করতে হয়নি।

## ৩. manifest.json — অ্যাপের পরিচয়পত্র

```json
{
  "name": "Troxela",
  "short_name": "Troxela",
  "description": "বন্ধুদের সাথে পোস্ট, ছবি, মেসেজ ও ফলো — সব এক জায়গায়।",
  "lang": "bn",
  "start_url": "/",
  "scope": "/",
  "display": "standalone",
  "orientation": "portrait",
  "background_color": "#ffffff",
  "theme_color": "#059669",
  "icons": [
    { "src": "/icons/icon-192.png", "sizes": "192x192", "type": "image/png", "purpose": "any" },
    { "src": "/icons/icon-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any" },
    { "src": "/icons/icon-512-maskable.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
```

- **`display: standalone`** — অ্যাপ খুললে ব্রাউজারের বার থাকে না, আসল অ্যাপের মতো দেখায়।
- **`start_url: /`** — আইকনে চাপ দিলে হোমপেজ খোলে।
- **`theme_color: #059669`** — Troxela-র সবুজ রং; ফোনের স্ট্যাটাস বার এই রঙের হয়।
- **`scope: /`** — পুরো সাইট (`troxela.store/...` সব পাতা) অ্যাপের ভেতরে থাকে।

## ৪. sw.js — Service Worker কীভাবে কাজ করে

Service worker হলো ব্রাউজারের ভেতরে চলা একটা ছোট প্রোগ্রাম — পাতা বন্ধ থাকলেও এটা ক্যাশ সামলায়।

### ধাপ ১ — Install: অ্যাপের খোলস ক্যাশে রাখা

প্রথমবার সাইট খুললেই এগুলো ফোনে জমা হয়:

```
/, /css/app.css, /manifest.json,
/icons/icon-192.png, /icons/icon-512.png,
/icons/icon-512-maskable.png, /icons/apple-touch-icon.png
```

### ধাপ ২ — Fetch: কোন জিনিস কীভাবে আসবে

| জিনিস | নিয়ম | মানে |
|---|---|---|
| পাতা (হোম, প্রোফাইল, মেসেজ...) | **Network first** | আগে ইন্টারনেট থেকে নতুন পাতা আনে; নেট না থাকলে ক্যাশের পুরনো পাতা, তারপর "ইন্টারনেট নেই" পাতা |
| CSS / JS | **Stale-while-revalidate** | ক্যাশের কপি সাথে সাথে দেখায়, পেছনে নতুন কপি এনে ক্যাশ আপডেট করে — তাই ডেপ্লয়ের পর পুরনো ডিজাইন ফোনে আটকে থাকে না |
| ছবি, ফন্ট, আইকন | **Cache first** | ক্যাশে থাকলে সেখান থেকে, না থাকলে নেট থেকে এনে ক্যাশে রাখে |
| চ্যাটের লাইভ ডেটা (`/messages/.../updates`, `/messages/.../history`) | **কখনো ক্যাশ নয়** | সবসময় নেটওয়ার্ক থেকে — নইলে পুরনো মেসেজ দেখাতো |
| POST / PUT / DELETE (পোস্ট করা, লাইক, মেসেজ পাঠানো) | **কখনো ক্যাশ নয়** | শুধু GET অনুরোধই ক্যাশের আওতায় আসে |

### ধাপ ৩ — Activate: পুরনো ক্যাশ মোছা

নতুন ভার্সন এলে পুরনো ক্যাশ (`troxela-v1` বদলে `troxela-v2` হলে) নিজে নিজে মুছে যায়।

## ৫. ইনস্টল ব্যানার কীভাবে কাজ করে

- অ্যান্ড্রয়েড Chrome-এ ব্রাউজার নিজে `beforeinstallprompt` ইভেন্ট পাঠালে নিচে একটা ব্যানার ওঠে — **"Troxela অ্যাপ ইনস্টল করুন"** + **ইনস্টল করুন** বোতাম।
- ব্যানার বন্ধ (×) করলে **৭ দিন** আর দেখায় না।
- অ্যাপ ইনস্টল করা থাকলে ব্যানার আর কখনো ওঠে না।
- আইফোনের Safari-তে Chrome-এর মতো ব্যানার হয় না — সেখানে **Share বোতাম → Add to Home Screen** চাপতে হয়, ব্যানারে সেটাই লেখা থাকে।

ব্যানারের কোড `pwa-banner.blade.php`-এ, আর service worker রেজিস্টার করার লাইনটাও ওই ফাইলেই:

```js
navigator.serviceWorker.register('/sw.js')
```

## ৬. ফোনে ইনস্টল করবেন কীভাবে

### অ্যান্ড্রয়েড (Chrome)

1. troxela.store খুলুন।
2. নিচে **"Troxela অ্যাপ ইনস্টল করুন"** ব্যানার এলে **ইনস্টল করুন** চাপুন।
3. ব্যানার না এলে: Chrome মেনু (⋮) → **"Install app"** / **"Add to Home screen"**।

### আইফোন (Safari)

1. Safari দিয়ে troxela.store খুলুন।
2. নিচের **Share** বোতাম চাপুন → **Add to Home Screen** → **Add**।

ইনস্টল হলে হোম স্ক্রিনে সবুজ "T" আইকন আসবে, চাপ দিলে অ্যাপের মতো খুলবে।

## ৭. যাচাই করবেন কীভাবে

### লাইভে (সরাসরি লিংক)

- https://troxela.store/manifest.json — `Troxela` আর `standalone` লেখা থাকতে হবে
- https://troxela.store/sw.js — `troxela-v1` লেখা থাকতে হবে
- https://troxela.store/icons/icon-192.png — আইকন দেখা যেতে হবে
- হোমপেজের সোর্সে `rel="manifest"` আর `theme-color #059669` থাকতে হবে

### কম্পিউটারের Chrome DevTools দিয়ে

1. troxela.store খুলে `F12` চাপুন → **Application** ট্যাব।
2. বামে **Manifest** — নাম, আইকন, theme color দেখা যাবে; কোনো ভুল থাকলে লাল করে দেখায়।
3. বামে **Service Workers** — `sw.js` Activated / running দেখাবে।
4. **Cache Storage → troxela-v1** — ক্যাশ হওয়া ফাইলগুলো দেখা যাবে।

### অফলাইন পরীক্ষা

DevTools-এর **Network** ট্যাবে **Offline** টিক দিয়ে পাতা রিলোড করুন — ক্যাশের পাতা বা "ইন্টারনেট সংযোগ নেই" পাতা দেখাবে, সাদা পাতা বা এরর দেখাবে না।

## ৮. ভবিষ্যতে আপডেট করবেন কীভাবে

### শুধু ডিজাইন (CSS) বা লেখা বদলালে

কিছু করতে হয় না। CSS লিংকে `?v=...` ভার্সন অটো বদলায়, আর service worker নিজে নতুন CSS এনে ক্যাশ আপডেট করে।

### শেলের ফাইল বদলালে (যেমন নতুন আইকন, নতুন CSS ফাইল)

`public/sw.js`-এর প্রথম দিকে ভার্সন বাড়ান:

```js
const CACHE = 'troxela-v1';   // → 'troxela-v2'
```

আর নতুন ফাইলটা `SHELL` তালিকায় যোগ করুন। তারপর আগের মতো GitHub-এ পুশ করে cPanel দিয়ে ডেপ্লয় করুন। পুরনো ক্যাশ ফোন থেকে নিজে নিজে মুছে যাবে।

### নতুন ফিচার যোগ হলে

- নতুন **GET API** (যেমন লাইভ নোটিফিকেশন) যোগ হলে, সেটা যেন ক্যাশ না হয় — `sw.js`-এর চ্যাট-বাইপাসের মতো করে তার পথটাও বাদ দেওয়ার তালিকায় রাখুন।
- নতুন পাবলিক ফাইল (ছবি/ফন্ট) নিজে নিজে cache-first নিয়মে ক্যাশ হবে — কিছু করতে হয় না।

| সমস্যা | সমাধান |
|---|---|
| ইনস্টল ব্যানার আসছে না | Chrome-এ সাইটটা ২ বার ভিজিট করুন; অথবা মেনু → Install app। ব্যানার বন্ধ করে থাকলে ৭ দিন অপেক্ষা করতে হয়, অথবা ব্রাউজার ডেটা সাফ করুন |
